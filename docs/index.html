Why Shellfie

Keep the terminal. Lose the screenshot ritual.

Hand-captured terminal images go stale, vary by machine, and are hard to review. Shellfie makes every visual an editable source file that belongs in version control.

Compose
Render static or animated visuals without executing commands.
Run
Drive a real PTY with waits, assertions, limits, and redaction.
Record

Quick start

From zero to a checked-in visual.

Ruby 3.0+ and ImageMagick are required.

1

Install

gem install shellfie
2

Describe

version: 1
theme: macos
title: "Terminal"

lines:
  - prompt: "$ "
    command: "echo hello"
  - output: "hello"
3

Generate

shellfie generate terminal.yml \
  -o terminal.png
